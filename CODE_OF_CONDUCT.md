# Code of Conduct

## Our commitment

Packy aims to be a respectful, constructive space for everyone, regardless of experience level, background, identity, or personal circumstances.

We want participation to be welcoming and harassment-free. Contributors are expected to communicate respectfully, assume good faith while discussing technical disagreements, and focus critique on ideas and code rather than people.

## Expected behaviour

Examples of behaviour that helps create a positive environment include:

- Being respectful, patient, and constructive.
- Giving and receiving technical feedback professionally.
- Welcoming questions from people with different levels of experience.
- Acknowledging mistakes and correcting them thoughtfully.
- Respecting privacy and not publishing another person's personal information without consent.

## Unacceptable behaviour

Examples of unacceptable behaviour include:

- Harassment, threats, discriminatory language, or personal attacks.
- Trolling, deliberate intimidation, or sustained disruption of discussions.
- Publishing private information without permission.
- Unwanted sexual attention or other conduct that would be inappropriate in a professional community.

## Scope

This code applies in Packy project spaces, including GitHub issues, pull requests, discussions, and project-related public communication.

## Reporting and enforcement

Report conduct that violates this code to the project maintainer through GitHub. For sensitive reports, contact the maintainer privately rather than posting details in a public issue.

The maintainer will review reports as fairly and confidentially as reasonably possible, and may remove content, close discussions, restrict participation, or take other action appropriate to the circumstances.

This policy is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), but this file is a project-specific code of conduct rather than a verbatim copy of that template.
